# Virtual-Lab

Виртуальная лабораторная работа, основанная на работе "Расчет и измерение параметров электромагнитных волн в направляющих системах" часть 2 под названием "Волны Н11 и Е01 в круглом волноводе".

ВЛР позволяет студентам, не имеющим возможность посещать очные лаболаторные работы, выполнить ее у себя дома за компьютером.
